## DESIGN SYSTEM

### Colors (use exact hex values — no substitutions)

| Role | Name | Hex |
|------|------|-----|
| Primary / Ink | Near-black | `#181d26` |
| Canvas | White | `#ffffff` |
| Signature Coral | Full-bleed voltage | `#aa2d00` |
| Signature Forest | Full-bleed voltage | `#0a2e0e` |
| Surface Dark | Dark card | `#181d26` |
| Cream | Soft callout | `#f5e9d4` |
| Body text | Dark gray | `#333840` |
| Muted text | Mid gray | `#41454d` |
| Hairline / borders | Light gray | `#dddddd` |
| On dark surfaces | White text | `#ffffff` |
| Storm Blue (logo only) | Electric | `#1147e8` |

**Rule:** Never use gradients, blobs, glows, or mesh backgrounds. Brand voltage comes from the solid signature card surfaces, not atmospheric effects. Canvas posts are pure white — nothing in the background.

### Typography

Font: **Inter** (Google Fonts). Weight distribution:
- 400 — display headlines and body. NOT bold.
- 500 — subtitles, buttons, captions, eyebrows
- 700 — short eyebrow labels only (uppercase, letter-spacing 0.18em)

**Type scale for posts:**
- Stat number: 140px / weight 500 / letter-spacing -0.04em
- Display headline: 64px / weight 400 / line-height 1.05 / letter-spacing -0.02em
- Section headline: 44px / weight 400 / line-height 1.1
- Subtitle / lede: 20px / weight 400 / line-height 1.5
- Eyebrow label: 13px / weight 700 / uppercase / letter-spacing 0.18em
- List items: 18px / weight 400 / line-height 1.6
- Caption / URL: 13px / weight 500 / letter-spacing 0.04em

**Rule:** Emphasis comes from SIZE, not weight. A 64px headline at weight 400 is more powerful than a 32px headline at weight 700. Never go above weight 500 for display type.

### Spacing

- Post padding: 64px sides, 56px top/bottom
- Gap between headline and lede: 32px
- Gap between list items: use a 1px hairline (`#dddddd`) divider
- Border radius: 12px for signature cards, 10px for content cards inside posts

### Post Dimensions
- Single feed posts: **1080 × 1080 px**
- Carousel slides: **1080 × 1350 px**

### 5 Post Surfaces

Every post uses one of these five surfaces. Text color is dictated by the surface.

1. **Canvas** — background `#ffffff`, headlines `#181d26`, body `#333840`, muted `#41454d`, eyebrow `#aa2d00`
2. **Coral** — background `#aa2d00`, all text `#ffffff`
3. **Forest** — background `#0a2e0e`, all text `#ffffff`
4. **Dark** — background `#181d26`, all text `#ffffff`
5. **Cream** — background `#f5e9d4`, headlines `#181d26`, body `#333840`

### Logo / Wordmark (appears on every post)

Top-left corner, small:
- Lightning bolt SVG icon (simple, sharp, 2–3 points) in `#1147e8` (Storm Blue) when on canvas/cream; white on dark/coral/forest
- "**STORM**" in weight 700, letter-spacing 0.12em
- "DIGITAL" in weight 400, same size, slightly muted
- On dark surfaces: full white. On canvas: ink.

Bottom-right corner, every post:
- "storm.mkt.agency" — 13px / weight 500 / muted color matching surface

Bottom-left corner:
- Post number "01 / 25" — same style as URL

### 3 Post Templates

**BOLD template:**
- Eyebrow label (top, colored)
- Large display headline (2–4 lines, 64px/400)
- Lede paragraph below (20px/400)
- CTA or handle at bottom

**STAT template:**
- Eyebrow label
- Giant stat number (140px/500) — the entire visual weight of the post
- Short headline explaining the stat (28px/400)
- Brief lede (18px/400)

**LIST template:**
- Eyebrow label
- Section headline (44px/400)
- 3–5 items separated by hairline dividers
- Each item: 18px/400, max 60 characters

## CONSISTENCY RULES (apply to every creative)

1. **One idea per post.** If you're tempted to add a second point, make it a separate post.
2. **Storm Digital wordmark** top-left on every post. Scale: ~120px wide.
3. **storm.mkt.agency** bottom-right on every post. 13px/500.
4. **Post number** bottom-left on every post. Format: "01 / 25" or "C1 · 01 / 05".
5. **No decorative backgrounds.** Canvas posts are pure `#ffffff`. No texture, no pattern, no gradient.
6. **Stat numbers** always use tabular figures (`font-variant-numeric: tabular-nums`). No decimals unless meaningful.
7. **Surface rotation** — never use the same surface twice in a row in the calendar. Alternate: canvas → coral → canvas → forest → canvas → dark → canvas → cream.
8. **CTA always present** — every post closes with an action: DM "AUDIT" / visit storm.mkt.agency / Swipe → / Save this.
9. **Eyebrow labels** always uppercase, always colored (coral on canvas/cream; white on dark surfaces).
10. **Max 4 list items** if showing on a 1080×1080. Up to 5 items on 1080×1350 carousel slides.
